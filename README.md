## 🌟 نظرة عامة (Overview)
تطبيق ويب عالي الأداء للمنيو الديجيتال التفاعلي والطلب عبر واتساب لمطعم **FIRE & ASH — TASTE THE FLAME** في البدرشين (أول طريق أبو ربع، بجوار مسجد شكري لبنة).

التطبيق مبني بدون قوالب الذكاء الاصطناعي المكررة (Anti-AI Slop)، معتمداً على لغة تصميم فحمية حقيقية مستوحاة من ألوان وهوية اللوجو الرسمي، بحركة فيزيائية 60 إطاراً في الثانية (GPU-accelerated)، وتجربة قرار سريعة تحول تردد الزبون إلى طلب واتساب مكتمل التنسيق في أقل من 30 ثانية.

## ⚡ المزايا والخصائص التفاعلية (Features)

1. **25 صنفاً موثقاً بدقة 100% (Verbatim Menu):**
   - **ساندوتشات (8 أصناف):** كفتة (50 ج)، حواوشي (50 ج)، شيش طاووك (45 ج)، بانيه (45 ج)، سجق (50 ج)، طرب (75 ج)، حواوشي جبنة موزاريلا (70 ج)، حواوشي مكس جبن (70 ج).
   - **الوزنات (6 أصناف مع مبدل أوزان تفاعلي):** فراخ شيش (فرخة 360 ج / 1/2 فرخة 180 ج / 1/4 فرخة 90 ج)، بانيه مشوي (كيلو 420 ج / 1/2 كيلو 210 ج / 1/4 كيلو 105 ج)، شيش طاووك (كيلو 420 ج / 1/2 كيلو 210 ج / 1/4 كيلو 105 ج)، كفتة (كيلو 440 ج / 1/2 كيلو 220 ج / 1/4 كيلو 110 ج)، سجق مشوي (كيلو 400 ج / 1/2 كيلو 200 ج / 1/4 كيلو 100 ج)، طرب ضاني (كيلو 600 ج / 1/2 كيلو 300 ج / 1/4 كيلو 150 ج).
   - **الوجبات المميزة (5 وجبات):** وجبة الأبطال (135 ج)، وجبة مكس فاير (150 ج)، وجبة أحمد ربيع الكردي (155 ج)، وجبة الحريف (215 ج)، وجبة مكس كردي (270 ج).
   - **الإضافات والسلطات (6 أصناف):** أرز بسمتي (30 ج)، أرز بشعرية (20 ج)، طحينة (10 ج)، سلطة خضراء (7 ج)، خيار مخلل (10 ج)، طماطم مخللة (10 ج).

2. **صور حقيقية مقصوصة لكل صنف:**
   - تم استخراج صور جميع الـ 25 صنفاً واللوجو الرسمي من المطبوعات الأصلية بصيغة `WebP` فائقة الخفة في مجلد `/public/images/dishes/`.

3. **شريط قرار حركي («محتار تطلب إيه؟»):**
   - فلترة لحظية حسب المزاج (الكل / ساندوتش سريع / وجبات تشبّع / مشويات بالوزن / سلطات وإضافات).
   - محرك بحث نصي فوري للأصناف والمكونات.

4. **مبدل أوزان ديناميكي (Interactive Weight Switcher):**
   - تبديل مباشر للأوزان داخل كروت الوزنات بحركة `layoutId` ناعمة وتحديث لحظي لعداد الأسعار الرقمي (`tabular-nums`).

5. **درج تفاصيل الصنف مع البيع الإضافي الذكي («كمّل أكلك»):**
   - مكونات الوجبة وتفاصيل الشواء.
   - إضافة سريعة بنقرة واحدة للسلطة والطحينة والأرز والمخلل.
   - اختيار ملاحظات الشيف (حار / سبايسي، بدون بصل، طحينة زيادة، تسوية زيادة) مع حقل نصي حر.

6. **سلة مشتريات عائمة ودرج دفع متكامل:**
   - شريط عائم عند اختيار أصناف يعرض الإجمالي والعدد.
   - درج Checkout باختيار نوع الطلب (توصيل للمنزل / استلام من الفرع).
   - فحص فوري لرقم الهاتف المصري (`^01[0125][0-9]{8}$`).
   - إرسال رسالة عربية منسقة بجميع التفاصيل إلى واتساب المطعم `01120774455` عبر رابط مشفر `encodeURIComponent`.

7. **استعراض المنيو الورقي الرسمي عالي الدقة:**
   - نافذة تفاعلية تتيح للزبون تقليب الصفحات الأربع الأصلية للمنيو الورقي المطبوع وتحميلها.

8. **استقرار وأمان كامل:**
   - تغليف التطبيق بـ `React Error Boundary` لمنع الشاشات البيضاء.
   - حفظ تلقائي للسلة في `localStorage` داخل كتل `try/catch`.
   - احترام تفضيل تقليل الحركة `prefers-reduced-motion`.

## 🛠️ الحزمة التقنية (Tech Stack)
- **Framework:** React 19 + TypeScript (Strict Mode)
- **Bundler:** Vite
- **Styling:** Tailwind CSS v4 (`@tailwindcss/vite` with `@theme` tokens)
- **Motion:** Framer Motion (GPU-only transforms & opacity)
- **Icons:** Lucide React (مع حظر كامل للإيموجيز في العناوين والتبويبات)
- **Deployment:** Vercel (مع ملف `vercel.json` لإعادة توجيه SPA)

## 🌐 النشر على Vercel (Deployment)

1. اربط مجلد المشروع بمستودع GitHub:
```bash
git add .
git commit -m "feat: complete FIRE & ASH digital menu and whatsapp ordering app"
git remote add origin <your-github-repo-url>
git push -u origin master
```
2. ادخل على [Vercel](https://vercel.com) واختر **Add New Project** ثم استورد المستودع.
3. الإعدادات الافتراضية ستعمل فوراً (`npm run build` ومجلد الإخراج `dist`).
4. ملف `vercel.json` المرفق يتكفل بمنع أخطاء 404 عند التحديث.
